# Deployment

This repository is connected directly to the Vercel project serving
[`davidvandykeinsurance.com`](https://davidvandykeinsurance.com).

- Pull requests receive a Vercel preview deployment.
- Pushes and merges to `main` deploy automatically to production.
- Production deployments should not require a manual `vercel --prod` command.

The GitHub-to-Vercel production path was verified through a pull request on
August 5, 2026.
