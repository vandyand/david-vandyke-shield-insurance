# David VanDyke Insurance Website

Professional landing page for David VanDyke, an independent insurance agent with Shield Insurance Agency serving West Michigan and beyond.

**Live site**: [davidvandykeinsurance.com](https://davidvandykeinsurance.com)

## About

This is a static landing page designed to build trust and convert visitors into insurance leads. David is an independent agent licensed in 9 states (AZ, FL, IL, IN, MI, MO, NC, OH, UT) who can shop multiple carriers to find the best coverage at the right price.

### Key Features

- Modern, professional design using Tailwind CSS
- Mobile-first responsive layout with hamburger navigation
- Dave Ramsey Endorsed Local Provider (ELP) since 2006
- Contact form powered by Formspree
- A/B testing support for CTAs via URL parameters
- Geo-targeting for West Michigan visitors

## Tech Stack

- **HTML5** - Semantic markup
- **Tailwind CSS** - Utility-first styling via CDN
- **Datastar.js** - Lightweight client-side reactivity
- **Lucide Icons** - SVG icon system
- **Google Fonts** - Inter typeface
- **Formspree** - Form submission handling
- **GitHub Pages** - Static hosting

## Development

This is a static site with no build process. Simply edit `index.html` and push to deploy.

```bash
# Clone the repo
git clone https://github.com/vandyand/david-vandyke-shield-insurance.git

# Open in browser
open index.html

# Deploy (push to main or gh-pages)
git push origin main
```
